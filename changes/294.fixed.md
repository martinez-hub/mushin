In a notebook, `resume=True` and `cache_dir=` now compare every project module a cell imports, whether or not the task names it, as `from pkg import sub` already did. A submodule the task reaches through an argument, a call's result, a parameter's default or a local name such as `m = pkg if a else None` is compared too. On Python 3.15, a second `cache_dir` run in the same kernel now reuses the cells when the task reads a module past a `lazy import pkg.sub`. With `cache_dir=`, importing another project module in a cell can now make the cells compute again.
