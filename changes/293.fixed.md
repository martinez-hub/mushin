In a notebook, `resume=True` and `cache_dir=` now also compare a project submodule the task reaches through an alias of its package (`m = pkg`, `s = pkg.sub`, a parameter defaulting to `pkg`), through the import of a function a class or a decorator is made in, or through a class-body import a method's default names. On Python 3.15, `lazy import pkg.sub` records the package `pkg` binds, as `import pkg.sub` does, so a second `cache_dir` run in the same kernel reuses the first run's cells when the task uses `pkg` only by name; it used to record `pkg/sub.py` too until the proxy resolved.
