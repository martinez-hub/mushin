In a notebook, `resume=True` and `cache_dir=` now also compare a project submodule the task reaches through an alias of its package (`m = pkg`, a parameter defaulting to `pkg`), from a class or a decorator made inside a function, or through a class-body import a method's default names. A parameter or local named like a module (`for model in models`) no longer records that module, so editing it no longer re-runs the cells. On Python 3.15, `lazy import pkg.sub` records the package `pkg` binds, as `import pkg.sub` does, before the proxy resolves and after; it used to record `pkg/sub.py` too until the proxy resolved, so a second `cache_dir` run in the same kernel missed when the task did not name `pkg.sub`.
