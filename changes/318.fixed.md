A sweep over lists or dicts of strings (`a=multirun([["x"], ["yy"]])`), or a raw comma sweep of quoted strings (`overrides=["+a='x','yy'"]`), no longer gives an all-NaN dataset: Hydra kept those strings quoted, so no cell matched its grid coordinate. The coordinates and the dry-run preview now show the plain values. Two spellings of one string in a raw sweep, such as `'x',"x"`, are now refused as duplicate values, since both run as the same cell.
