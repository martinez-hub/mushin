A sweep over lists or dicts of strings (`a=multirun([["x"], ["yy"]])`), or a raw comma sweep of quoted strings (`overrides=["+a='x','yy'"]`), no longer gives an all-NaN dataset: Hydra kept those strings quoted, so no cell matched its grid coordinate. The coordinates and the dry-run preview now show the plain values. Sweep values that would share a cell are now refused as duplicates, as two equal values already were: two spellings of one string (`'x',"x"`), or a string and a number of one text. `multirun(["1", 1])`, for one, ran before with one cell's result overwriting the other's.
