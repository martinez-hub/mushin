`resume=True` and `cache_dir=` read more of a driver script the way it runs. A decorator alias, a registration inside an `if` block, a `match` capture, a class body reading the global it shadows (`SCALE = SCALE`) and a `from __future__` import now count, so an edit there re-runs the cells. A main block's `else` branch, which does not run, no longer counts. A comprehension variable, a nested function's local and an annotation without a value are no longer taken for code the task reads, so editing them does not re-run cells.
