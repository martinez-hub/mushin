`resume=True` and `cache_dir=` read more of a driver script the way it runs. A decorator alias, a `match` capture and a `from __future__` import now count, so an edit there re-runs the cells, and so does moving an assignment between a main block's body and its `else`. A comprehension variable, a nested function's local and an annotation without a value are no longer taken for code the task reads, so editing them does not re-run cells. A definition registered inside a block (`if ENABLED: @register class ...`) and a class body reading the module's name it shadows (`SCALE = SCALE`) are still not compared.
