`resume=True` and `cache_dir=` read a task defined in the driver script as the script runs as `__main__`: a name read while a statement runs is the binding before it, and a name a function reads is any binding of it. A decorator alias, a registration inside a block or on an object the task reads (`@scale.register`), a `match` capture, a class body reading the global it shadows, a main block's `else` branch (which does not run) and a `from __future__` import are now read as they run, and a comprehension variable named like a global is not taken for it. Reordering independent definitions is not an edit. A statement that changes an object in place (`CFG["lr"] = 0.1`), or a function that rebinds a global when called, is still not compared.
