`resume=True` and `cache_dir=` compare a task defined in a notebook (IPython, Jupyter) by the cells the kernel ran, in the order it ran them: an edited and re-run helper or constant cell re-runs the cells that read it, while re-running a cell unchanged, or the cell that extends the grid, is not an edit. A cell that raised counts up to the statement that raised, once mushin has seen the kernel run a sweep; the project modules of the values the task reads are followed by their types, and a parallel worker records the cells as the driver read them. A driver script is now read the same way, as it runs as `__main__`: a name read while a statement runs is the binding before it, and a name a function reads is any binding of it, so a decorator alias, a registration inside a block, a `match` capture, a class body reading the global it shadows, a main block's `else` branch and a `from __future__` import are read as they run, and a comprehension variable named like a global is not taken for it. A notebook or script statement that changes an object in place (`CFG["lr"] = 0.1`), or a function that rebinds a global when called, is still not compared.
