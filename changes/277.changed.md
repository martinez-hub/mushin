`resume=True` and `cache_dir=` read more of a driver script the way it runs. A decorator alias, a decorator that registers through a helper, a registration inside an `if` block, a `match` capture, a class body reading the global it shadows (`SCALE = SCALE`) and a `from __future__` import now count, so an edit there re-runs the cells. A main block's `else` branch, which does not run, no longer counts. A comprehension variable, a nested function's local, an annotation without a value, and a name used only in a function-local annotation are no longer taken for code the task reads, so editing them does not re-run cells, and a script records the same on Python 3.11 to 3.14.
