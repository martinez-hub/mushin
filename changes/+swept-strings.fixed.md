A swept string now reaches the task as written. One that reads as another type in an override, such as `multirun(["true", "null", "1"])`, reached the task as `True`, `None` or `1`, and the first two cells were NaN; such cells recompute on resume. A backslash in a string, swept or fixed (`"C:\data"`), is no longer doubled. A sweep of two or more values is now written in Hydra's comma form (`a='x','y'`), so `multirun.yaml` and the launch log show quoted strings; results and cell keys are unchanged, and a sweep that holds `None` among other values now runs. A one-value sweep of such a string (`multirun(["true"])`) cannot be written so that it arrives unchanged and now raises before launch: pass it as a fixed value. A glob sweep's error now says glob is not supported.
