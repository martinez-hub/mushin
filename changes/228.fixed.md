The statistics guide said 5 seeds make a Wilcoxon test viable; the floor is 6 (its best-case two-sided p-value is `2 ** (1 - n_seeds)`), so the documented remedy for the underpowered-test warning produced the same warning. The guide no longer recommends the default Wilcoxon test for small seed counts either, and the LLM guide's seed-count advice no longer states a fixed threshold as if power were independent of effect size.
