A driver script's code record now counts a script name that a class body reads before binding it: `lr = lr`, `lr += [3]`, `for lr in lr:`, a read before `lr = ...`, a read after a binding inside an `if` or a `del`, or a method's default or a decorator argument before the binding. Python reads such a name from the script until a binding in the class body runs. This holds wherever the class is: at the top level, in a block, in the main block, in a function or in another class. Before, editing such a name (`lr = 0.1` to `lr = 0.2`) reused the completed cells on `resume=True` or `cache_dir=`. A read after a binding that runs only in some branches (a `try` that binds the name in each) counts too, which may recompute once too often. A script whose class body reads such a name recomputes once after upgrading.
