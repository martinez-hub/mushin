`mushin.slurm(gpus=, cpus=, mem_gb=, timeout_min=, partition=, account=, qos=, setup=)` builds the `launcher_config` of a sweep whose cells each run as one SLURM job of one task, for `launcher="submitit_slurm"`, without importing Lightning; `mushin.submitit_slurm_config` stays the helper for DDP cells, which run a task per GPU. Where `scontrol` answers, it refuses a named partition that does not exist, or a time limit past the partition's, before anything is submitted, naming the partitions that fit (`check=False` skips it). It judges the partition, time and QoS sbatch will use, so an `SBATCH_PARTITION`, `SBATCH_TIMELIMIT` or `SBATCH_QOS` in the environment counts (and warns when it overrides an argument); it never picks a partition, and leaves GPUs and accounts to SLURM.
