A new guide, Running a sweep on SLURM, covers an ordinary sweep on a cluster without an `sbatch` script of your own: installing the `slurm` extra, describing each cell's job with `mushin.slurm`, submitting from a login node and keeping the driver running, what the jobs need (a shared filesystem), where each cell's directory and job logs are, watching, failed cells, resuming and cancelling. The packing guide gains a section on running a sweep inside one SLURM allocation, and the agent guide routes "run each cell as a SLURM job" to the new guide.
