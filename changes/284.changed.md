`resume=True` and `cache_dir=` follow `import pkg.sub` in a notebook. The statement binds only `pkg`, so `pkg/sub.py` was not compared, and after an edit to it and a restart, a resume reused the old results. The record now reads such statements from the cells the kernel keeps, while `pkg` is still bound to the package; under a parallel launcher, whose workers keep no cells, write `from pkg import sub`, which counts the same. Taking the record also no longer runs a module loaded through `importlib.util.LazyLoader`, which reading any of its attributes would do.
