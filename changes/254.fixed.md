A sweep reloaded with `load_from_dir` now reports every cell of its grid that has no result, as `.run()` does: failed cells in `.failures`, and the rest (skipped, still running, or never started because the sweep was killed) in `.skipped`. `to_xarray()` carries them as the `mushin_failures` / `mushin_skipped` attrs, and `is_complete` reflects them. Before, `compare_methods` on such a reloaded sweep compared it as if it were complete instead of raising `IncompleteSweepError`. Holm correction then covered fewer comparisons, so it could report a pair as significant that the complete sweep does not support. Loading into a workflow object that already ran also no longer keeps that run's metrics.
