`show`, `diff`, the `dry_run=True` preview and `python -m mushin guide --path` no longer fail with `UnicodeEncodeError` on a console that cannot encode what they print (a Windows pipe in cp1252, a cp437 console, `PYTHONIOENCODING=ascii`): a swept value, metric name or path outside the console's encoding prints as a backslash escape such as `\u03b1`, while the returned `.table` keeps the text itself. mushin's own console text, warnings and error messages are now plain ASCII, so the `diff` table heads its delta columns `<metric> (b-a)` instead of `Δ<metric>` (code that parses `DiffResult.table` must look for the new header; `DiffResult.rows` is unchanged) and the dry-run preview opens with `Dry run: N cells`.
