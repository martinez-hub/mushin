A cell swept over a non-finite value (`inf`, `-inf`, NaN) is now recorded so it reads back as that value: `mushin.show`, `best`, `diff` and the CSV export list the finished cell (`show` dropped it once its sweep finished), its resume finds its own checkpoint, a resume after the sweep's manifest was lost reuses it, and mushin's submitit launchers keep its result when its job's return is lost. When a cell is matched with its record, a swept NaN is no longer taken for a swept None (both were stored as `null`), nor `True` for `1`. A record written by an earlier version keeps a NaN as `null`, which reads back as None.
