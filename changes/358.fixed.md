On Windows, writing a cell's status or metrics file no longer fails the cell while another process is reading the file, such as `mushin.show` on a running sweep: mushin retries for up to about two seconds. Removing a cell's earlier metrics file (when it is skipped, fails, or its job dies) waits the same way, where it used to leave the old metrics beside the new record, for `show`, `best` and export to list. A process that holds a file longer (a sync client, an antivirus scan) still fails the write.
