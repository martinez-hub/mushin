A fixed or swept value holding an OmegaConf interpolation no longer breaks the sweep once its jobs have run. A fixed `out="${hydra:runtime.output_dir}"` made `run()` raise after every cell had completed, and reloading the directory failed too; a swept value such as `"${now:%H-%M}"` that resolved differently by the time mushin read it could leave a completed cell NaN. mushin now reads such a value unresolved, as the sweep's override holds it, so `multirun_task_overrides`, the dataset's coordinate and the manifest show the interpolation (`"${now:%Y}"` where a swept one used to show the year). Resuming a sweep made by an earlier release may rerun the cells whose swept value is an interpolation.
