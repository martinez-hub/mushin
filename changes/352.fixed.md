A fixed value holding an interpolation that cannot be resolved once the sweep's jobs have run, such as `out="${hydra:runtime.output_dir}"`, no longer makes `run()` raise after every cell has completed, nor makes a reload of the directory or `target_dir_multirun_overrides` raise: mushin reads that value as written. An interpolation the driver can resolve, such as `"${base_lr}"`, reads as its value in `multirun_task_overrides` and the dataset, as before.
