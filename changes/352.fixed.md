A fixed value holding an interpolation that cannot be resolved once the sweep's jobs have run, such as `out="${hydra:runtime.output_dir}"`, no longer makes `run()` raise after every cell has completed, and no longer stops a reload of the directory: mushin reads that value as written. A swept one no longer stops `run()` either: it warns, and the cells whose value holds it come back NaN, since each job resolved the value for itself. An interpolation that can be resolved, such as `"${base_lr}"`, reads as its value, as before.
