The workflows guide now documents a known upstream incompatibility: on `hydra-core == 1.3.6`, a config built with **both** `zen_partial=True` and `zen_wrappers=` raises `InstantiationException: Callable targets cannot return partial subclasses`. hydra-core 1.3.6 hardened `instantiate` so a callable target may no longer return a `functools.partial` subclass, which is what hydra-zen produces when those two options are combined — either alone is fine. mushin itself is unaffected (it uses `zen()`, a different feature, and never `zen_wrappers`), but the error names neither Hydra nor hydra-zen, so it is easy to mistake for a bug in your own task function. The note gives the fix and recommends pinning the single version out (`hydra-core != 1.3.6`) over a blanket ceiling.
