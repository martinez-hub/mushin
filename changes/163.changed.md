Migrated the MCP server to the MCP Python SDK v2: the `mcp` extra now
requires `mcp >= 2, < 3` (the 1.x line is in maintenance mode upstream). The
server's tools, transport (stdio), and `mushin-mcp --root` CLI are unchanged;
if you pin `mcp` 1.x elsewhere in your environment, stay on the previous
mushin release until you can upgrade.
