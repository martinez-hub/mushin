On `launcher="submitit_slurm"` or `"submitit_local"`, a job of one task that ends without returning after its cell has completed (its result reached the driver too late, say) can now keep the cell's result rather than become a failed cell. A cell's `mushin_cell_status.json` now records the run that wrote it and its job (`run_id`, `job_id`), and, for a completed cell, whether its metrics file holds the result whole (`metrics`), which is how mushin tells the job's own completed record from one an earlier run left.
