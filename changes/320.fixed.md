A backslash in a string passed to `run`, swept or fixed (`"C:\data"`, `multirun(["a\\b", "c"])`), no longer reaches the task doubled: mushin escaped every backslash, but Hydra unescapes only one that precedes a quote. A string holding an interpolation (`${...}`), which OmegaConf parses with escapes of its own, is written as before. A glob sweep's error now says `glob(...)` is not supported and names the parameter without its `+`.
