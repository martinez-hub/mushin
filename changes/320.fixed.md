A swept string reaches the task as written. A sweep of two or more values holding a string that reads as another type in an override, such as `multirun(["true", "null", "1"])`, handed the task `True`, `None` or `1`, and the first two cells were NaN; such a sweep is now written in Hydra's comma form (`a='true','null','1'`), which keeps the quotes into each job, and its cells recompute on resume. Every other sweep is written as before, so its job overrides and Hydra's `override_dirname` are unchanged. A backslash in a string, swept or fixed (`"C:\data"`), is no longer doubled. A glob sweep's error now says glob is not supported. A one-value sweep of such a string (`multirun(["true"])`) can still reach the task retyped; pass it as a fixed value.
