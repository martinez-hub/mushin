A reload (`load_from_dir`) no longer raises `FileNotFoundError` for a completed cell whose task returned no metrics: such a cell has no `mushin_metrics.json`, and its record, from this version on, says it wrote none, so the reload gives it NaN, as the run does. A cell whose record names a metrics file that is now missing (lost, or copied without it), a record from an earlier version, and a missing file of your own still raise.
