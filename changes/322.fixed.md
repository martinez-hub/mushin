On Python 3.12+, a generic definition in a driver script (`def task[T](x: T)`, `class task[T](Base[T])`, `type Vec[T] = list[T]`) no longer counts its own type parameter as a read of a module-level name of the same name. Editing such a binding (a leftover `T = TypeVar("T")`) recomputed every cell on `resume=True` or `cache_dir=`, though the task never read it. A script with such a binding recomputes once after upgrading.
