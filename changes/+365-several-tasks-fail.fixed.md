In a job of several tasks (`tasks_per_node > 1`, or several nodes), a cell now fails when any of its tasks raises, under `on_error="nan"` as under `"raise"`. The run took the first task's result even when another task had raised, and the cell's record was whichever task wrote last, so a reload could call the cell failed while the run had its value, or completed (with another task's metrics) while the run had failed it. A completed record left by such a job is now recorded failed when mushin collects the job, and the cache entry its completing task wrote is removed.
