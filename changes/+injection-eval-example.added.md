New `examples/prompt_injection_eval.py` measures resistance to indirect prompt injection — the attack arriving inside retrieved content rather than from the user — and compares systems with mushin's statistics. Detection uses an inert canary, and the example reports whether a resistance gap survives a re-run and a different set of attacks, plus a per-attack breakdown that surfaces blind spots an aggregate score hides. Run `--demo` to see it without a model or keys.
