Each job's `.hydra/hydra.yaml` now names the `run()` that launched it (`hydra.job.mushin_run_id`), as the cell's status record does (`run_id`). The override that sets it is also listed in `hydra.overrides.hydra` and in the sweep's `multirun.yaml`, so two otherwise identical runs now differ there. When mushin's submitit launchers record a job that died before Hydra made its dir, over no record or an unfinished one, the snapshot they write names this run too, instead of an earlier run's left in a reused dir.
