On Python 3.14 and later, a task whose annotations name an import made only for type checking (`if TYPE_CHECKING: from decimal import Decimal`, then `def task(a: int, h: Decimal = None)`) now runs. Before, `.run()` raised `NameError` because mushin, and hydra-zen's `zen` through it, read the task's signature by evaluating its annotations. When evaluating them fails that way, mushin now reads the signature with each annotation kept as its text, for the task and for `pre_task`. As a result, mushin no longer catches a misspelled name in such an annotation at `.run()`; Python 3.14 already stopped catching it at the definition. hydra-zen's own `builds(task, populate_full_signature=True)` in your code still evaluates the annotations.
