`load_from_dir`, and the MCP tools that read a sweep directory, are about 9x faster: reloading a 1000-cell sweep took 0.8 s instead of 7.3 s. Each cell's `.hydra/hydra.yaml` is now read as plain YAML, with the C parser that PyYAML's wheels include, instead of being built into an OmegaConf config. PyYAML, which OmegaConf already installs, becomes a direct dependency (`pyyaml >= 6.0.3`).
