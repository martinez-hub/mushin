`load_from_dir`, and the MCP tools that read a sweep directory, are about 4.5x faster: reloading a 1000-cell sweep took 1.6 s instead of 7.3 s. Each cell's `.hydra/hydra.yaml` is now parsed by the libyaml that PyYAML's wheels include, instead of being built into an OmegaConf config. The parse is used only when OmegaConf would accept every value in the file and writing the parsed tree back as Hydra writes `hydra.yaml` reproduces the file exactly; any other file, hand-edited or malformed, goes through OmegaConf as before, with the same result or error. PyYAML, which OmegaConf already installs, becomes a direct dependency (`pyyaml >= 6.0.3`). `load_from_dir` on a directory with no job directories now raises a `FileNotFoundError` that says why, instead of `ValueError: not enough values to unpack`; one that fails partway leaves nothing behind, so a later call reloads; and a mistyped path leaves the workflow as it was.
