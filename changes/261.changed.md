`load_from_dir`, and the MCP tools that read a sweep directory, are about 5x faster: reloading a 1000-cell sweep took 1.4 s instead of 7.3 s. Each cell's `.hydra/hydra.yaml` is now parsed by the libyaml that PyYAML's wheels include, instead of being built into an OmegaConf config. The parse is used only when the file is exactly the text Hydra writes and OmegaConf would accept every value in it; any other file, hand-edited or malformed, goes through OmegaConf as before, with the same result or error. PyYAML, which OmegaConf already installs, becomes a direct dependency (`pyyaml >= 6.0.3`). A sweep directory with no job directories now raises a `FileNotFoundError` that says why, instead of `ValueError: not enough values to unpack`.
