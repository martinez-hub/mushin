`load_from_dir`, and the MCP tools that read a sweep directory, are about 7x faster: reloading a 1000-cell sweep took 1.1 s instead of 7.3 s. Each cell's `.hydra/hydra.yaml` is now read as plain YAML, parsed by the libyaml that PyYAML's wheels include and checked by OmegaConf's own rules, instead of being built into an OmegaConf config. A file OmegaConf would reject or resolve differently still goes through OmegaConf, as before. PyYAML, which OmegaConf already installs, becomes a direct dependency (`pyyaml >= 6.0.3`). A sweep directory with no job directories now raises a `FileNotFoundError` that says so, instead of `ValueError: not enough values to unpack`.
