`mushin.show` and `mushin.export.table` no longer lose the values of a swept parameter named `status`: the cell status overwrote them, and the column appeared twice. The parameter is now the column `status (param)`, as a metric that clashes is already `<name> (metric)`; `status` is always the cell status. Likewise `mushin.diff` keeps a swept parameter named `deltas`, as `deltas (param)` in its rows and table.
