The resilience guide's Lightning recipe for a cell that resumes its own training now writes the checkpoint where `mushin_resume.last_ckpt` looks: `ModelCheckpoint(dirpath=mushin_resume.dir, save_last=True)`. The recipe it gave (`default_root_dir` with `ModelCheckpoint(save_last=True)`) saved it under `lightning_logs/`, so `last_ckpt` was always None and the cell never resumed. The guide also no longer says a cell is never handed another cell's checkpoint: a sweep over another grid in the same `working_dir` can do that, so run it in a new one.
