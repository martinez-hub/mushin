A swept value written as an interpolation is now keyed by what the sweep's cells resolved it to, not resolved again when the sweep is read back: the value they agree on (so `${base_lr}` keys as `0.01`, as before), else the interpolation's text. A cell whose value resolves differently later (`${now:...}`, a counter) is no longer NaN, an interpolation of another swept value (`${model_name}_x`) and a swept `${hydra:...}` no longer stop `run()` and a reload, and a reload keys the cells as the run did. A fixed value holding an interpolation still reads as it did.
