The MCP server's `get_metrics` serves a run directory's `mushin_metrics.json` only when the directory's record says its run completed, and is the run its `.hydra/` snapshot names. It paired each directory's config with whatever metrics file was there, so a cell whose job had failed, was still running, or died before its first record in a reused `working_dir` was served an earlier run's metrics as its own (#407). A directory with no record (a plain Hydra run) is served as before.
