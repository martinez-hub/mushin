`run()` no longer imports torch to record the accelerator in each cell's `mushin_provenance.json` when the process has not imported it already. A sweep that does not use torch (a scikit-learn comparison, say) starts about half a second sooner and records `null` accelerator values, where it previously recorded the machine's device; a sweep whose task module imports torch or Lightning records them as before. A task that imports torch only inside its body now records `null` as well.
