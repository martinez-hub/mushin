Each cell's `mushin_provenance.json` records the accelerator (CUDA and cuDNN build, device) from the process that ran the cell, once its task has returned, instead of from the process that called `run()` before the first cell. A task that imports torch inside its body, and a sweep launched from a login node with submitit, now record the device the cell ran on. A sweep that never imports torch no longer imports it to record `null` values, which saves the torch import (about half a second here) on every `run()`; `mushin.diff` compares the accelerator only when both sweeps recorded one, so a torch sweep against a scikit-learn sweep on the same machine reports no hardware change.
