The `diff` table heads its delta columns `<metric>(b-a)` instead of `Δ<metric>`, a character cp1252 and cp437 lack (migration: code that parses `DiffResult.table` matches `acc(b-a)` where it matched `Δacc`; the header still splits on whitespace into one token per column, and `DiffResult.rows` is unchanged). `export.table(root, path=...)` writes its CSV in UTF-8 without a byte-order mark on every platform instead of the locale's encoding (cp1252 on Western Windows, which failed on a metric name outside it); pandas and polars read it as is (migration: in Excel on Windows, open it with Data > From Text/CSV, or the import wizard, and choose UTF-8).
