`mushin.best(root, metric, over="seed")` returns the configuration whose metric, averaged over the named swept parameters, is best, so picking a configuration no longer rewards one lucky seed. `combo` omits the averaged parameters, `value` and `metrics` are means, `n` counts the cells and `dirs` lists their job dirs. Only complete groups count: those with a result at every seed where any configuration has one. The others are skipped with a warning, as is a sweep still running, whose bar is the seeds reached so far. `best()` without `over=` is unchanged, except that an infinite metric value no longer counts as finite: it cannot be the best cell, and `diff` prints no delta for it instead of an infinite or NaN one.
