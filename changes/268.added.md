`mushin.best(root, metric, over="seed")` returns the configuration whose metric, averaged over the named swept parameters, is best, so picking a configuration no longer rewards one lucky seed. `combo` omits the averaged parameters, `value` and `metrics` are means, `n` counts the cells and `dirs` lists their job dirs. Only groups whose every cell completed count; the others are skipped with a warning, and `best()` without `over=` is unchanged.
