Before, such an edit was missed and a resume reused cells computed with the old code. mushin now reads such a cell as Python compiled it, from the shell's input history or, for a cell run after `import mushin`, from what it saw the cell run, and reads the project modules such a cell imports and the classes it states the same way. A function whose definition still cannot be found, as in such a cell that ran inside another cell (`%%capture`) before `import mushin`, now re-runs its cells instead of reusing results. A resume re-runs the cells once after upgrading for a task that reaches a function defined in such a cell.
