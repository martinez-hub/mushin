A second sweep into the same `working_dir` no longer leaves an earlier sweep's `mushin_metrics.json` in a cell whose task returns no metrics: the cell's first record in a run removes a file another run left (in a job of several tasks, a task that starts after another finished keeps what that one wrote). Reloading such a cell now raises `FileNotFoundError`, as a fresh directory always has (#364), instead of reading the earlier sweep's value.
