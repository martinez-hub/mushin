`mushin.show` lists a cell whose submitit job is submitted but has not started as `queued`, and `show(jobs=True)` adds each cell's job id, host and log folder (`job`, `host`, `logs`). The launcher names each submission's jobs in a file under `<working_dir>/mushin_jobs/` and removes it once it has waited on them. During a resume, a cell sent to a job again is `queued` in place of its earlier record until that job starts; `best(over=)` counts queued cells as unfinished (#345).
