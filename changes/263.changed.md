`run` records each cell's Hydra job number and config-group choices in the cell's status sidecar (`mushin_cell_status.json`), and `load_from_dir` and the MCP server read them from there instead of parsing the cell's `hydra.yaml`, which was most of a reload's time: a 1000-cell sweep run on this version reloads in about 0.5 s instead of 1.5 s. Sweeps from earlier versions, and a cell whose `hydra.yaml` is newer than its sidecar, are read as before.
