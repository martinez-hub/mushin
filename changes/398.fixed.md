A cell's `mushin_provenance.json` records its config as written: an interpolation such as `${oc.env:DB_URL}` is kept as its text. hydra-zen's `zen`, the default task wrapper, resolves a job's config in place before the task runs, and the record was taken after that, so every value an interpolation read, an environment variable included, was written to disk whatever its key's name (#383). Records written by earlier versions may hold such values: the `mushin_provenance.json` in each cell's directory, and the `provenance` attribute of a dataset built by `to_xarray` (and of a netCDF file saved from it). Check or delete them before sharing a sweep. A config holding a value json cannot write now gets a record (an Enum by its name, a Path as its text); it got none. The MCP `get_config` docs now say what it serves, the config as written.
