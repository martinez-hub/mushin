On `launcher="submitit_slurm"` or `"submitit_local"`, a cell whose job ended without a result after its task had finished (a job of several tasks one of which died, or a result submitit could not save) is now recorded failed, as the run reports it, so a resume runs it again: before, its record stayed completed, and a resume reused the value the run had failed, as did a reload (`load_from_dir`), `mushin.show` and a later run with the same `cache_dir`. Its metrics file and its `cache_dir` entry are now removed. When a cell's job died before the cell started, in a `working_dir` an earlier run had used, a reload returned that run's result for the cell; with `on_error="nan"` it now reports the cell failed, as the run did, `show` leaves the cell out, and a resume can still reuse the earlier result.
