A `hydra_list` value now reaches the task as written. A backslash is no longer doubled (`hydra_list(["a\\b"])` arrived as `['a\\\\b']`), `None` arrives as `None` rather than the string `'None'`, and a nested tuple, dict or `range` inside it now reaches the task where it used to fail to parse. A nested `hydra_list`, `multirun` or OmegaConf `ListConfig` still arrives as a list. A dict key that would not reach the task as itself is now refused before launch with a `ValueError` naming it. That covers a string key that reads as another type (`"1"` arrived as `1`), one holding `=` or `:`, one with a leading or trailing space, and a `None` key, which OmegaConf does not take. Hydra has no quoted dict keys: use a key Hydra writes as itself, or build the dict in the task. `HydraDDP` now quotes a re-launched rank's run directory and job name as Hydra's own writer does. A path or a `job_name=` holding a quote, `=` or `,` used to break every child rank. Not changed: in a string holding `${`, a backslash that is neither right before the `${` nor inside the interpolation may still arrive doubled; write such a path with `/`, or put the value in the config.
