In a notebook, the code record now counts a function or class defined in a cell that an annotation of the reached code names: a parameter's, a return's, a class attribute's (a dataclass field's) or a type parameter's, in a string too (`def task(x: Helper)`, `x: "Helper"`, `list["Helper"]`). Editing such a class reused the completed cells on `resume=True` or `cache_dir=`, though `typing.get_type_hints`, pydantic and hydra-zen's `builds(..., populate_full_signature=True)` resolve the edited one. What such a definition reaches by name or by its own annotations counts too. A notebook whose task's annotations name a cell's definition recomputes once after upgrading.
