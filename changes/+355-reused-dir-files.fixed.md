A sweep run again into the same `working_dir` no longer passes an earlier sweep's results off as its own: a cell whose task returns no metrics removes a `mushin_metrics.json` an earlier cell left in its directory, and a reload no longer reads an earlier cell's record and metrics for a cell whose job died after Hydra wrote its `.hydra/` and before the cell recorded anything (its combo or config differs from the record's); that cell is NaN and counts as not run.
