In a notebook, `resume=True` and `cache_dir=` now compare a project submodule the task reaches through its package (a cell's `import pkg.sub`, then `pkg.sub.X` in the task, a helper, a class's bases, a decorator or a default), and the project modules a notebook function imports inside its body. Before, editing `pkg/sub.py` and resuming reused the completed cells. A resume keeps the record a reused cell was written with, so a sweep started on 0.17.0 still does not compare such a submodule: after editing one, use a new `working_dir`. A notebook task whose record gains such a file misses `cache_dir` once after upgrading.
