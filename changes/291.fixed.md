In a notebook, `resume=True` and `cache_dir=` now compare a project submodule the task reaches through its package (a cell's `import pkg.sub`, then `pkg.sub.f(...)` in the task or a helper), and the project modules a notebook function imports inside its body. Before, editing `pkg/sub.py` and resuming reused the completed cells. On Python 3.15, a second `cache_dir` run in the same kernel after `lazy import pkg.sub` now reuses the first run's cells. A notebook task whose record gains such a file misses `cache_dir` once after upgrading.
