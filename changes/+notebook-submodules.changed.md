`resume=True` and `cache_dir=` follow the submodules a notebook reaches through a package: after `import pkg.sub` in a cell, which binds only `pkg`, an edit to `pkg/sub.py` re-runs the cells, as it does for a task defined in a file. On Python 3.15, `lazy import pkg.sub` keeps the same record once the task resolves it, so a second `cache_dir` run in the same kernel reuses the cells.
