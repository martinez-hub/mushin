For a task defined in a notebook, `resume=True` and `cache_dir=` now compare a class with no method of its own (a dataclass or an `Enum` of fields, a class of constants) by its `class` statement, and a class whose every method a notebook decorator wraps. In a running IPython shell mushin notes which cell bound each class: a class whose cell states it is read from that statement, and one a cell binds without stating it (a `%%time` cell's, an `exec`'s, a `%run` file's, a `global` factory's, or a copy such as `dataclass(slots=True)(C)`) re-runs its cells instead of reusing results, whenever that cell runs again and after a restart. So does a class whose kept versions cannot be told apart. A resume re-runs the cells once after upgrading for a task that reaches a class with no method of its own.
