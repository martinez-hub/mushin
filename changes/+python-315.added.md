Python 3.15 is now supported and tested on Linux, Windows and Apple Silicon. It needs torch 2.15 or later, and the hydra-zen floor is now 0.17.1, the first release that imports on 3.15. A sweep recorded on an earlier Python and resumed on 3.15 still reuses its completed cells: the syntax trees `resume` and `cache_dir` compare leave out the field 3.15 adds to every import (PEP 810's `is_lazy`), which would otherwise have changed the record of every file that imports anything. PyYAML has no 3.15 wheel yet, so it builds from source; without libyaml, `hydra.yaml` files are read through OmegaConf, with the same results, more slowly.
